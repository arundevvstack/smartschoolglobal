# SmartSchool Global

An enterprise-grade, multi-campus school management ERP platform built with Next.js 15, Tailwind CSS, TypeScript, and modern interactive modules.

## Features

- 🌐 **Global Multi-Campus Management**: Consolidated reporting across worldwide campuses with localized currency, timezone, and curriculum compliance.
- 🎓 **Student 360° Profile**: Live attendance, grade tracking, behavioral badges, parent links, and health metrics.
- 📈 **Interactive Admissions Pipeline**: Multi-stage CRM for lead capture, tour scheduling, document verification, and seat allocation.
- 🚌 **Live Fleet & Bus Map**: Real-time vehicle telematics, route optimization, speed monitoring, and arrival ETA.
- 💳 **Cashless Smart Wallet & POS**: RFID wristband/card integration, dietary restrictions enforcement, balance top-up, and transaction logs.
- 🛡️ **Gate & Access Command Center**: Biometric & RFID turnstile sync, visitor passes, automated perimeter lockdown, and SMS check-in/out alerts.
- 🤖 **AI Assistant for School Operations**: Natural language command simulator for instant report generation, timetable adjustments, and emergency drills.
- 🏢 **Hostel, Incident, Workforce & Finance Suites**: Complete modules for residential schools, disciplinary actions, payroll, and fee collection.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Lucide React Icons
- **SEO**: Structured schema, dynamic sitemap & robots.txt

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production

```bash
npm run build
npm run start
```
